# ECommerce REST API

ECommerce REST API is a backend application built with Spring Boot for handling user authentication, product management, and order processing.
The project uses secure role-based access control for Admin and Customer users.

## Features

* JWT Authentication & Authorization
* Role-based access (ADMIN / CUSTOMER)
* Product CRUD operations
* Product search, pagination, and sorting
* Order placement and order history
* Product image upload support
* Global exception handling
* Swagger API documentation

## Tech Stack

* Java
* Spring Boot
* Spring Security
* Spring Data JPA
* MySQL
* JWT
* Maven
* Swagger
* Railway

## API Modules

* Authentication APIs
* Admin APIs
* Customer APIs
* Order APIs
